## Portal-Windows 1.5.3 Herta 🪄✨

---

### 🇷🇺 Русский язык

#### 🌟 Новые возможности
- **🛡️ Удалённое подтверждение UAC (Контроль учётных записей / CredUI):** 
  - Теперь всплывающие запросы прав администратора Windows можно подтверждать в одно касание со смартфона или часов!
  - Автоматическая адаптация плитки: в окне UAC скрыты избыточные поля имени пользователя, а на экране блокировки сохраняются полные данные.
  - Автоматическая отправка запроса на подтверждение при появлении диалога CredUI.
- **🚨 Экстренная отмена (Hotkeys `Left Ctrl` + `Left Alt`):**
  - Глобальный перехват сочетания клавиш на активном рабочем столе (как в Winlogon, так и на защищённом столе Consent/UAC).
  - Мгновенная отмена зависшего или нежелательного удалённого запроса с немедленным возвратом фокуса в локальное поле ввода пароля.
- **🔘 Нативные кнопки управления Windows:**
  - Кнопки «Повторить» и «Отмена» переведены на официальный стиль Windows SDK (`CPFG_STYLE_LINK_AS_BUTTON`).
  - Эргономичные закруглённые кнопки в стилистике Windows 10/11, расположенные сразу под полем ввода пароля.
- **📊 Переключатель деталей подключения:**
  - Возвращена кнопка «Показать подробности» / «Скрыть подробности».
  - Отображение счётчика активных клиентов в реальном времени (`Сеть: N, Bluetooth: M`).

#### ⚡ Улучшения и оптимизация
- **🌐 Сетевая стабильность и mDNS:**
  - Динамическое разрешение локальных имён хоста и машины без жёстко зашитых псевдонимов.
  - mDNS отвечает на запросы имени компьютера напрямую, игнорируя виртуальные адаптеры (TUN/VPN) и локальные APIPA-адреса.
  - Сохранение состояния ожидающих подтверждений при кратковременном переподключении сокетов.
- **🧱 Встроенная служба брандмауэра:**
  - Полный отказ от внешних bat-скриптов в пользу встроенного C#-сервиса `FirewallService`, автоматически настраивающего правила Windows Defender Firewall.
- **🇷🇺 Полная локализация интерфейса:**
  - Добавлен перевод статусов «Запрос отменён», исправлено зацикливание префикса «Состояние:».
  - Восстановлено постоянное отображение актуального номера версии на плитке блокировки (`Версия: 1.5.3`).
- **✍️ Автоматическая цифровая подпись:**
  - Интеграция этапа `SignPublishOutput` в процесс сборки с автоматическим проставлением доверенных меток времени (Sectigo Timestamp).
  - Чистые метаданные версий без лишних хешей коммитов.

#### 🔄 Совместимость
- **📱 Мобильный клиент:** Обратно совместим с мобильным клиентом Portal для Android и Wear OS.
- **🔐 Протоколы:** Форматы REST, WebSocket и Bluetooth сохранены без ломающих изменений.

### 🇬🇧 English

#### 🌟 What's New
- **🛡️ Remote UAC Elevation (Credential UI / CPUS_CREDUI):**
  - Approve Windows User Account Control (UAC) administrative elevation prompts seamlessly from your phone or smartwatch!
  - Smart tile adaptation: redundant username inputs are hidden in CredUI dialogs, keeping the lock screen clean and intuitive.
  - Automatic unlock request dispatch as soon as the CredUI elevation prompt appears.
- **🚨 Emergency Rollback Shortcut (`Left Ctrl` + `Left Alt`):**
  - Dedicated low-level keyboard hook active across both Winlogon and secure Consent/CredUI desktops.
  - Instantly aborts any pending remote unlock request and returns direct focus to the local password field for manual entry.
- **🔘 Native Action Push Buttons:**
  - Migrated "Retry" and "Cancel" controls to the official Windows SDK push-button style (`CPFG_STYLE_LINK_AS_BUTTON`).
  - Modern, rounded push buttons matching the ergonomics of Windows 10/11 logon screens.
- **📊 Connection Details & Live Stats:**
  - Restored interactive "Show details" / "Hide details" toggle button on the provider tile.
  - Real-time client connection counters (`Network: N, Bluetooth: M`).

#### ⚡ Improvements & Hardening
- **🌐 Network Resilience & mDNS:**
  - Dynamic host and computer name resolution instead of hardcoded host aliases.
  - Multicast DNS directly resolves hostname queries while filtering out TUN/VPN virtual adapters and link-local APIPA addresses.
  - In-flight approval states are preserved across transient WebSocket reconnects.
- **🧱 Native Windows Firewall Integration:**
  - Replaced ad-hoc batch scripts with built-in `FirewallService` for automated, non-intrusive firewall rule configuration.
- **🌐 Russian Localization Polish:**
  - Added localization for "Request canceled" statuses and eliminated redundant "Status:" prefix loops.
  - Restored permanent version label visibility on the tile (`Version: 1.5.3`).
- **✍️ Automated Code Signing & Build Pipeline:**
  - Automated Authenticode signing with Sectigo RFC 3161 timestamps integrated into MSBuild publishing.
  - Clean `ProductVersion` attributes (`1.5.3-Herta`) without noisy commit SHA suffixes.

#### 🔄 Compatibility
- **📱 Mobile App:** Fully compatible with Portal for Android and Wear OS.
- **🔐 Protocols:** WebSocket, REST, and Bluetooth transport specifications remain fully backward-compatible.
